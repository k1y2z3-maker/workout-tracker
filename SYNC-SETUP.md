# Workout Tracker V1.0
Static PWA. No user records or Google credentials in source. Use Google Identity Services OAuth token client with a Web application OAuth client, JavaScript origin https://k1y2z3-maker.github.io, Sheets API enabled, and test user configured if app is in Testing. Enter client ID and private spreadsheet ID in app settings. Do not share client secret. Access token is held in memory and expires; reauthorize manually. The app requires Historical sheet 歷史紀錄 columns A:X and 器械對照 A:C. It preserves Q/R array formulas, writes individual rows only, and caps writes at row 501. Deletion clears data fields and retains ID/tombstone. Do not edit the same row simultaneously in Sheets and App: optimistic read/compare/write is not atomic compare-and-swap. Directly added rows without IDs are read-only until assigned a unique ID. Do not sort only a subset of columns; keep each record with its ID. New exercises are appended when authorized. Local-only custom exercises must first be created in the cloud with matching IDs before their records can sync. JSON export includes local cache/queue and must be kept private. No cloud API traffic is cached by service worker. Initial cloud test must use a separate test copy before real writes.
